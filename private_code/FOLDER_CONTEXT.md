# private_code

Рабочая зона агента: здесь ведётся собственная разработка решения.

## Правила работы

1. В начале сессии создать новую подпапку в формате `YYYY-MM-DD_тема`
   (например, `2026-08-13_baseline_lgbm`).
2. Работать внутри этой папки: код, эксперименты, промежуточные артефакты.
   Логи скриптов удобно класть в подпапку `logs/` внутри папки сессии
   (например, `2026-08-13_baseline_lgbm/logs/train.log`).
3. В конце сессии обязательно оставить в этой же папке отчёт о
   проделанной работе (например, `REPORT.md`) в свободной форме: что
   сделано, какие результаты/метрики получены, что не сработало, что
   делать дальше.

Каждая сессия — отдельная папка, старые папки не перезаписываются, чтобы
сохранялась полная история экспериментов.
