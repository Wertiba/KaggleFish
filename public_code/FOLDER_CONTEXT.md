# public_code

Публичный код по соревнованию: чужие ноутбуки, скрипты, baseline-решения,
скачанные с Kaggle (public kernels/notebooks) или из других открытых
источников.

Только для чтения и референса — источник идей и готовых кусков кода,
которые можно переиспользовать или от которых можно оттолкнуться.
Агент не редактирует файлы в этой папке, только читает.
